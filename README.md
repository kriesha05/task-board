# Task board with search and filter
A small react app for managing tasks with search and filter, and full CRUD

# Getting started
1. clone or dwnload this repo
2. run npm install
3. run npm run dev
4. open the URL (localhost:5173) from the terminal

# Features
1. Render tasks as a list or card grid, loaded from local mock data
2. free text search across title and description
3. filter by status and priority
4. add, edit and delete tasks
